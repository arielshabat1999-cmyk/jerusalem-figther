# Boss Progress UI Assets

Production asset folder for the NEON SURVIVOR in-run Boss Progress HUD.

Planned asset roles:
- BossProgress_Frame
- BossProgress_Track
- BossProgress_EnergyFill
- BossProgress_EnergyFlow_FX
- BossProgress_ProgressEdge

Dynamic values, BOSS labels, progress percentage, theme colors, and animation remain runtime-driven and must not be baked into artwork.
